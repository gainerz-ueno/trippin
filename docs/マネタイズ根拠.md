# Tabibi マネタイズの根拠

調べた日：2026-10-26。数字はすべて、下の出典（実際に開いたページ）か、このリポジトリの既存コードの箇所から取っています。出典のない数字は「わからないこと」に入れ、測り方を書いています。
コードの数字は `app/lib/plan.js` と `supabase/migrations/20261027_premium.sql` の2か所だけにあり、この文書と同じです（変えるときは3つ同時に）。

為替：1ドル＝157.15円（2026-10-26 10時、157円14銭〜16銭の真ん中。[琉球新報（共同通信）為替相場](https://ryukyushimpo.jp/kyodo/economics-k/exchange)）

## 推す料金と中身

- **プレミアム：月額480円／年額3,900円（税込・予定）**。決済はまだ作っていません（Stripe はあとで）。画面には「予定」と出し、「使いたい」の押された数を記録します。
- **有料の中身：「AIで作る」（eタビセツ・表紙・直す）の回数だけ**。無料は合計1回（お試し）、月払いは毎月10回、年払いは1年で87回。
- **無料のまま：本人が決めた機能すべて**（登録・カテゴリー・メモ・写真・営業時間・地図・宿泊先・回る順番・候補→行ったお店→eタビセツ（テンプレート）・自分だけのeガイドブック・共有・おすすめマーク・お土産・スクショ・Grab/Uber用のコピー）。
- **作り手の取り分（有料のeガイドブック）：売上 −（カード手数料3.6%）− 残りの10%（運営）＝ 約86.8%**。値段は作り手が100〜50,000円で決める。

**480円／3,900円にした理由**
1. 日本の「旅のしおり」アプリで有料版がある2つ（tabiori・NAVITIME Travel）が、どちらも**月480円**。tabiori は**年3,900円**。同じ値段にした（新しく決めた数字はない）。
2. 年3,900円は、Stippl（3,500〜4,000円）の範囲の中で、旅行アプリの真ん中（約3,143円）より上、Wanderlog（4,090円〜）より下。
3. 旅行アプリは66%が年払い（RevenueCat）なので、月払いと年払いの両方を出す（旅は年に何回かなので、使う月だけ払う人もいるはず。比率は記録で測る）。

**AIを有料の中身にした根拠**
- Wanderlog は AI を無料では回数制限、Pro で無制限にしている。Stippl も AI の旅程づくりを PRO にしている（上の表）。
- Tabibi の費用で一番大きいのが「AIで作る」（1回 最大約23.48円、下の計算）。ほかの機能（登録・地図・順番・テンプレート）は1回ごとの費用がない、か小さい。
- 本人が決めた機能（上の「無料のまま」）は有料にしない。

## 「AIで作る」の回数の計算

| 項目 | 数字 | 出典 |
|---|---|---|
| 1回の費用（絵1枚） | 2K画像 $0.134 | [Gemini API 料金（gemini-3-pro-image）](https://ai.google.dev/gemini-api/docs/pricing)。モデルと 2K は `app/api/noteai/route.js` の `MODEL`・`imageSize: '2K'` |
| 入れる写真 | 1枚 $0.0011 × 最大14枚 | 同上。14枚は `app/api/noteai/route.js` の `let room = 14` |
| → 1回の最大 | $0.1494 ＝ **約23.48円** | 上から計算（文字の入力トークンは未測定→「わからないこと」） |
| 決済の手数料 | カード3.6%＋Billing 0.7%＝4.3%（手元に95.7%） | [Stripe 料金](https://stripe.com/jp/pricing) |
| AIにかけてよい割合 | 売上の55%まで | AI製品の粗利の平均は45%（2025年）。[ICONIQ 2026 State of AI（SaaStr のまとめ）](https://saastr.com/the-builders-economy-10-metrics-from-iconiqs-newest-2026-state-of-ai-report)。残りの45%で Google マップ・Supabase・利益をまかなう |
| 旅行アプリの有料化率 | 1.78%（＝無料体験に進む4.1% × 体験から有料43.5%） | [RevenueCat 2026（Travel）](https://www.revenuecat.com/state-of-subscription-apps)。参考：全体の真ん中2.0%、日本を含むアジア太平洋2.4% |

- **月払い：480円 × 95.7% × 55% ÷ 23.48円 ＝ 10.76 → 10回／月**
- **年払い：3,900円 × 95.7% × 55% ÷ 23.48円 ＝ 87.4 → 87回／年**
- **無料：1.78% × 3,900円 × 95.7% × 55% ÷ 23.48円 ＝ 1.56 → 合計1回**（新しく入った1人から見こめる売上は約66.6円。アジア太平洋の2.4%で計算すると2.1回なので、低いほうの旅行の数字を使った）
- うまく描けなかったときは回数を戻す（前からの決まり。`ai_quota_refund`）。「直す」も1回に数える（前からの決まり。1回ごとに同じ費用がかかるため）。
- 運営者のアカウントは制限なし（前からの決まり。`UNLIMITED`、動作確認用）。

**前の決まり（1日3回・無料）からの変更**：1日3回は根拠がなく、続けると1人で月に最大 3×30×23.48＝約2,113円かかる（月額480円の4倍以上）。上の計算に置きかえた。

**決めたこと**
- 運営の取り分は **カード手数料（Stripe 3.6%）を引いた残りの10%**。日本の作り手がふだん比べる note・Brain・Tips の中で一番低い note と同じ形・同じ率にした（作り手が「note より損」と思わない）。端数は切り捨て（note と同じ。作り手に多く残る）。
- 例：500円 → カード18円・Tabibi 48円・**作り手434円**（画面にもこの内訳を出す。`app/lib/plan.js` の `guideSplit`）
- 値段の範囲は **100〜50,000円**（note の有料記事と同じ。[note ヘルプ](https://www.help-note.com/hc/ja/articles/360011270114)）。
- 無料で見せるページは作り手がえらぶ（表紙だけ〜全部のページ）。note も無料で見せる部分を作り手が決める（同上）。最初の値は「表紙だけ」（新しく数字を決めないため）。
- 決済を作るときは Stripe Connect で作り手に払う。Stripe が料金を管理する形ならプラットフォームへの Connect 手数料はかからない。プラットフォームが料金を管理する形だと、作り手1人につき月$2＋0.25%＋25¢かかる（[Stripe サポート](https://support.stripe.com/questions/monetizing-payments-with-stripe-connect?locale=ja-JP)）ので、前者にする。お金を預かって作り手に渡す形になるので、作る前に Stripe と弁護士に確認する。

## わからないことと、測り方（記録を足しました）

記録は Supabase の `events`（決まった名前だけ。ログインしている人は「1人・1日・1つの出来事」で1回）。見方は SQL ファイルの一番下。

| わからないこと | 測り方 | 見る場所 |
|---|---|---|
| 無料からプレミアムに移る割合 | `prem_sheet`（案内を開いた）→ `prem_interest`（使いたい。detail＝month／year）→ 決済後は `entitlements` の人数 | `events`・`entitlements` |
| 月払いと年払いのどちらが多いか | `prem_interest` の detail（month／year） | `events` |
| 「AIで作る」の回数が足りるか | `ai_quota_hit`（使い切った画面を見た人）、`ai_uses`（1人あたりの回数） | `events`・`ai_uses` |
